# AD/EMB-110/13 Amdt 7 - Rudder Upper Hinge Support

**AIRWORTHINESS DIRECTIVE**

On the effective date specified below, and for the reasons set out in the background section, the CASA delegate whose signature appears below revokes Airworthiness Directive (AD) AD/EMB-110/13 Amdt 6 and issues the following AD under subregulation 39.001(1) of CASR 1998. The AD requires that the action set out in the requirement section (being action that the delegate considers necessary to correct the unsafe condition) be taken in relation to the aircraft or aeronautical product mentioned in the applicability section: (a) in the circumstances mentioned in the requirement section; and (b) in accordance with the instructions set out in the requirement section; and (c) at the time mentioned in the compliance section.

#### Embraer EMB-110 (Bandeirante) Series Aeroplanes

| AD/EMB-110/13 Amdt 7 | Rudder Upper Hinge Support | 16/2011 |
|---|---|---|

| Applicability: | All models S/Nos 110001 thru 110141, 110143 thru 110146, 110148, 110149, 110152, 110153, 110156, 110157, 110160, 110161, 110164, 110165, 110168 thru 110170, 110172 thru 110178, 110180, 110181, 110183, 110184, 110186, 110187, 110189, 110190, 110192 thru 110359, 110361 thru 110473, and 110475 thru 110480 |
|---|---|
| Requirement: | 1. Action in accordance with Embraer Service Bulletin 110-055-0017 Rev 04. |
|  | 2. (a) With the rudder removed from the aircraft, perform a dye penetrant inspection of the rudder upper hinge bracket, P/N 4A-3441, paying particular attention to the areas under and around the bolt supporting flange, or |
|  | 2. (b) With the rudder in situ, perform a detailed visual inspection of both parts of the rudder upper hinge bracket P/N 4A-3441, paying particular attention to the areas under and around the bolt supporting flange. |
| Compliance: | For Requirement 1: |
|  | Part I - Unless already accomplished, within 300 hours time in service after<br>7 June 1989. |
|  | Part II - Within 300 hours time in service after 7 June 1989, and thereafter at each C type inspection; until modified in accordance with Part III of the Requirement document. |
|  | For Requirement 2. (a): |
|  | Within 600 hours time in service after 27 December 1990, and thereafter at each C type inspection. |
|  | For Requirement 2. (b): |
|  | Within 300 hours time in service after 11 July 1991, and thereafter at each B2 type inspection. |
|  | The compliance times of the previous issue of this Directive are as stated. |

|  | This Amendment becomes effective on 5 August 2011. |
|---|---|
| Background: | Cracks in the rudder upper hinge support structure have been reported to the manufacturer. Amendment 3 was the result of further cracking due to rudder installation problems and also extended the periodicity. |
|  | Amendment 4 introduced an inspection of the rudder upper hinge brackets following three local reports of cracking. |
|  | Amendment 5 was issued to correct anomalies in Requirement and Background information, and introduce an alternative visual inspection for Requirement 2 (b). |
|  | Amendment 6 aligned the repeat inspection interval with existing scheduled inspections to include 5% tolerance on inspection intervals. |
|  | Amendment 7 is issued to align with the latest revision status of Embraer Service Bulletin 110-055-0017. |
