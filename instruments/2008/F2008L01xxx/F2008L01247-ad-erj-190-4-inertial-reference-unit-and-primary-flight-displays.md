# AD/ERJ-190/4 - Inertial Reference Unit and Primary Flight Displays

**AIRWORTHINESS DIRECTIVE**

For the reasons set out in the background section, the CASA delegate whose signature appears below issues the following Airworthiness Directive (AD) under subregulation 39.001(1) of CASR 1998. The AD requires that the action set out in the requirement section (being action that the delegate considers necessary to correct the unsafe condition) be taken in relation to the aircraft or aeronautical product mentioned in the applicability section: (a) in the circumstances mentioned in the requirement section; and (b) in accordance with the instructions set out in the requirement section; and (c) at the time mentioned in the compliance section.

#### Embraer ERJ-190 Series Aeroplanes

| AD/ERJ-190/4 | Inertial Reference Unit and<br>Primary Flight Displays | 5/2008 |
|---|---|---|

| Applicability: | All ERJ-190 aircraft models. |
|---|---|
| Requirement: | If not previously accomplished, remove the wiring connections from pins 51 and 52 in the electrical connectors of both Inertial Reference Units (IRU) in accordance with the procedures in Embraer Service Bulletin 190-34-0009 original issue dated 26 February 2007, or later revision approved by the Brazilian Agência Nacional de Aviação Civil (ANAC). |
|  | Note: ANAC AD 2007-08-04 refers. |
| Compliance: | Before 27 February 2009. |
|  | This Airworthiness Directive becomes effective on 8 May 2008. |
| Background: | The ANAC has advised of reports of IRU failures which lead to an erroneous flight path angle (FPA) indication on both primary flight displays, with no alert to this condition to the crew. On ERJ-190 aircraft, FPA is considered as important as pitch and bank angle for piloting purposes. |
|  | Since this condition affects flight safety, this Directive requires wiring changes which will improve IRU functionality. |
