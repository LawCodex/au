# Telecommunications (Integrated Public Number Database – Public Number Directory Additional Information) Instrument 2017

I, MITCH FIFIELD, Minister for Communications, make the following instrument.

Dated 18 July 2017

MITCH FIFIELD

Minister for Communications

Contents

###### 1 Name

This instrument is the *Telecommunications (Integrated Public Number Database – Public Number Directory Additional Information) Instrument 2017*.

###### 2 Commencement

This instrument commences on the day after this instrument is registered.

###### 3 Authority

This instrument is made under subsection 285(4) of the *Telecommunications Act 1997*.

###### 4 Definitions

In this instrument:

***Act*** means the *Telecommunications Act 1997*.

***integrated public number database scheme*** means the scheme in force under section 295A of the Act.

***public number directory*** has the meaning given by subsection 285(2) of the Act.

***public number directory authorisation*** has the same meaning as in the *Telecommunications (Integrated Public Number Database Scheme – Conditions for Authorisations) Determination 2017.*

***public number directory publisher*** has the same meaning given by section 1.4 of the *Telecommunications Integrated Public Number Database Scheme 2017.*

***qualifying entity*** has the meaning given by subsection 285(2) of the Act.

###### 5 Schedules

Each instrument that is specified in Schedule 1 to this instrument is repealed as set out in the Schedule.

###### 6 Specification

(1) Information that a qualifying entity and a public number directory publisher have agreed orally or in writing to include in a public number directory is specified for the purposes of subparagraph (c)(i) of the definition of ***public number directory*** in subsection 285(2) of the Act.

(2) Where a qualifying entity and public number directory publisher have an oral agreement under subsection (1), the information is only specified if the public number directory publisher:

(a) has created and retained a record of the agreement; and

(b) intends to keep a copy of the record of the agreement for a minimum of two years from the time of making it.

## Schedule 1—Repeals

##### Telecommunications (Integrated Public Number Database – Public Number Directory Additional Information) Instrument 2007 (No. 1)

**1 The whole of the instrument**

Repeal the instrument.
