# AD/EMB-120/32 Amdt 1 - Electrical Power System

**AIRWORTHINESS DIRECTIVE**

For the reasons set out in the background section, the CASA delegate whose signature appears below revokes Airworthiness Directive (AD) AD/EMB‑120/32 and issues the following AD under subregulation 39.001(1) of CASR 1998. The AD requires that the action set out in the requirement section (being action that the delegate considers necessary to correct the unsafe condition) be taken in relation to the aircraft or aeronautical product mentioned in the applicability section: (a) in the circumstances mentioned in the requirement section; and (b) in accordance with the instructions set out in the requirement section; and (c) at the time mentioned in the compliance section.

#### Embraer EMB-120 (Brasilia) Series Aeroplanes

| AD/EMB-120/32 Amdt 1 | Electrical Power System | 6/2005 |
|---|---|---|

| Applicability: | All EMB-120 and EMB-120RT series aeroplanes. |
|---|---|
| Requirement: | Modify the aeroplane in accordance with Embraer Service Bulletin 120-24-0051 Revision 05 dated 20 November 2001 or later revision approved by the Brazilian Centro Técnico Aeroespacial (CTA). |
|  | Note 1: Aeroplanes that have incorporated previous Revisions of SB 120-24-0051 require further action in accordance with revision 05. |
|  | Note 2: DAC Brazil AD 93-12-01R2 Amdt 39-940 refers. |
| Compliance: | Remains unchanged as ‘Within 1500 hours time in service after the effective date of the original issue of this Directive’. |
|  | This Amendment becomes effective on 9 June 2005. |
| Background: | The original issue of this Directive required removal of a LH DC relay box attaching bolt and washer to avoid interference with a relay contact. These actions were additional to those required by AD/EMB-120/10 Amdt 3 and AD/EMB-120/16. |
|  | The original issue of this Directive superseded AD/EMB-120/10 Amdt 3 and AD/EMB-120/16, which were cancelled. |
|  | This amendment allows compliance to be achieved by using later CTA approved revisions of the SB. |
|  | The original issue of this Directive became effective on 11 July 2002. |
