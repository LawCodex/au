# AD/BELL 430/5 - Never-Exceed Speed - Instrumentation Change

**AIRWORTHINESS DIRECTIVE**

For the reasons set out in the background section, the CASA delegate whose signature appears below issues the following Airworthiness Directive (AD) under subregulation 39.001(1) of CASR 1998. The AD requires that the action set out in the requirement section (being action that the delegate considers necessary to correct the unsafe condition) be taken in relation to the aircraft or aeronautical product mentioned in the applicability section: (a) in the circumstances mentioned in the requirement section; and (b) in accordance with the instructions set out in the requirement section; and (c) at the time mentioned in the compliance section.

#### Bell Helicopter Textron Canada (BHTC) 430 Series Helicopters

| AD/BELL 430/5 | Never-Exceed Speed - Instrumentation Change | 11/2005 |
|---|---|---|

| Applicability: | Bell Helicopter Textron Canada (BHTC) Model 430 helicopters as follows: |
|---|---|
|  | a. Serial Number (S/N) 49001 through 49103, equipped with Overspeed Warning Kit, Part Number (P/N) 430-706-004-101 or 430-706-004-103. |
|  | b. S/N 49001 through 49100, equipped with Single Automatic Flight Control System (AFCS) with Flight Director Kit, P/N 430-705-009-103, -105, -109,<br>-111, -115 or -117; or P/N 430-705-011-109, -111, -121 or -123. |
|  | c. S/N 49001 through 49100 equipped with Dual AFCS with Flight Director Kit, P/N 430-705-011-103, -105, -115, -117, -125, -127, -129, -133, -135 or<br>-137. |
| Requirement: | **Helicopters Equipped with Overspeed Warning Kit** - Unless already accomplished, carry out the following in accordance with Part 1 of BHTC Alert Service Bulletin (ASB) 430-05-35 dated 21 June 2005 or later revision approved by the Chief, Continuing Airworthiness, Transport Canada: |
|  | Replace the VNE Overspeed Warning Computer, the pilot and co-pilot Airspeed Indicator, and the VNE Converter, and |
|  | Remove the decal, P/N 430-075-070-103, from below the pilot and co-pilot Airspeed Indicators. |
|  | **Helicopters Equipped with Single or Dual AFCS with Flight Director Kit** - Unless already accomplished, carry out the following in accordance with Part 2 of BHTC ASB 430-05-35 or later revision approved by the Chief, Continuing Airworthiness, Transport Canada: |
|  | Replace the AFCS Air Data Computer Adapter module, and |
|  | Remove the decal, P/N 430-075-070-101, from above the pilot and co-pilot horizontal situation indicator (HSI) display. |
|  | Note: Transport Canada AD CF-2005-30 refers. |

| Compliance: | No later than 31 July 2007. |
|---|---|
|  | This Airworthiness Directive becomes effective on 27 October 2005. |
| Background: | Transport Canada has received advice from BHTC that following cold weather testing to establish VNE values at cold temperatures (-40°C) it was determined that modification to the helicopter’s instrumentation is required. This modification affects the software in the VNE Overspeed Warning Computer (required for certain operations) and in the AFCS Air Data Computer. The changes in the VNE Overspeed Warning Computer also necessitate the replacement of the pilot and co-pilot Airspeed Indicator and the VNE Converter. |
