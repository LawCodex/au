# AD/INST/38 - LITEF GmbH LCR-88 Attitude and Heading Reference System

**COMMONWEALTH OF AUSTRALIA** ***(Civil Aviation Regulations 1998)*****, PART 39 - 107 CIVIL AVIATION SAFETY AUTHORITY**

**SCHEDULE OF AIRWORTHINESS DIRECTIVES**

[image]\
Instruments and Automatic Pilots

AD/INST/38 LITEF GmbH LCR-88 Attitude and Heading Reference System

6/94

Applicability: Litef GmbH LCR-88 Attitude Heading Reference Units (AHRU) with the following part numbers, having Software Version 0202 incorporated:

121319-0011,

121319-0111,

121319-1010, and

121319-1032.

Requirement: Reprogramme the AHRU computer module software in accordance with Litef GmbH Service Bulletin 121319-34-003 Revision 1 dated 22 October 1993.

*Note: German LBA AD 93-240 Litef refers.*

Compliance: Prior to 31 August 1994.

Background: Litef has advised that Software Version 0202 sends incorrect scaling of angular rate outputs, reprogramming of the software as required by this Directive, corrects this anomaly.
