# AD/JETSTREAM/56 - Fairchild Type 1000 Flight Data Recorder

**COMMONWEALTH OF AUSTRALIA** ***(Civil Aviation Regulations 1998)*****, PART 39 - 105 CIVIL AVIATION SAFETY AUTHORITY**

**SCHEDULE OF AIRWORTHINESS DIRECTIVES**

[image]\
British Aerospace BAe 3100 (Jetstream) Series Aeroplanes

AD/JETSTREAM/56 Fairchild Type 1000 Flight Data Recorder 1/93

Applicability: All British Aerospace 3200 (JETSTREAM) Series aeroplanes fitted with a Fairchild Type F1000 Flight Data Recorder.

Requirement: Action IAW BAe Alert Service Bulletin 31-A-JA921050 dated 26 October 1992.

*Note: CAA (UK) AD 007-10-92 dated 3 November 1992 refers.*

Compliance: Prior to 01 April 1993.

Background: This action is required because an investigation following an incident has shown that an internal Flight Data Recorder failure was not indicated by the anunciator on the centre instrument panel.
