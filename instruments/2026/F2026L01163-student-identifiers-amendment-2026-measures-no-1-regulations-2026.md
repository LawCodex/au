## Schedule 2—VET data system authorisations

##### Student Identifiers Regulation 2014

**1 Section 4**

Insert:

***Data Provision Requirements*** has the same meaning as in the NVETR Act.

***Information Determination*** means the *National Vocational Education and Training Regulator (VET Data System Information) Determination 2026*.

***National VET data system*** has the same meaning as in the NVETR Act.

***National VET data system contract*** has the same meaning as in the Information Determination.

***non‑referring State*** has the same meaning as in the NVETR Act.

***VET data system*** has the same meaning as in the NVETR Act.

***VET data system contract*** has the same meaning as in the Information Determination.

***VET data system contractor*** has the same meaning as in the Information Determination.

**2 After section 16**

Insert:

###### 16A Authorisation—National VET data systems

(1) A VET data system contractor for a VET data system contract (that is a National VET data system contract) is authorised to collect, use or disclose a student identifier of an individual:

(a) for the purpose of designing, building, operating, maintaining or testing the National VET data system to which the contract relates; and

(b) in accordance with the contract.

(2) An entity is authorised to disclose to, or collect from, a VET data system contractor for a VET data system contract (that is a National VET data system contract) a student identifier of an individual in connection with the VET data system contractor carrying out a purpose mentioned in paragraph (1)(a) in accordance with the contract.

###### 16B Authorisation—other VET data systems

(1) A VET data system contractor for a VET data system contract (that is not a National VET data system contract) is authorised to collect, use or disclose a student identifier of an individual to the extent that subsection (3) applies.

(2) An entity is authorised to disclose to, or collect from, a VET data system contractor for a VET data system contract (that is not a National VET data system contract) a student identifier of an individual to the extent that subsection (3) applies.

(3) For the purposes of subsections (1) and (2), this subsection applies to the collection, use or disclosure of a student identifier if all of the following apply:

(a) the student identifier has been collected in accordance with the Data Provision Requirements, or any equivalent requirements in a non‑referring State;

(b) the collection, use or disclosure is:

(i) for the purpose of facilitating the provision of data in accordance with the Data Provision Requirements, or any equivalent requirements in a non‑referring State; and

(ii) if subsection (1) applies—for the purpose of designing, building, operating, maintaining or testing the VET data system to which the contract relates in accordance with the contract; and

(iii) if subsection (2) applies—in connection with the VET data system contractor carrying out a purpose mentioned in subparagraph (ii) of this paragraph in accordance with the contract;

(c) if the contract was entered into after the commencement of this section—the VET data system contractor is obliged under a contract, in relation to information that is:

(i) collected in accordance with the Data Provision Requirements, or any equivalent requirements in a non‑referring State; and

(ii) handled under the VET data system contract;

to comply with the Australian Privacy Principles as if the VET data system contractor were an APP entity (within the meaning of the *Privacy Act 1988*).
