###### 3 Authority

This instrument is made under subsection 214B(2) of the *National Vocational Education and Training Regulator Act 2011*.

###### 4 Definitions

Note: A number of expressions used in this instrument are defined in the Act, including the following:

(a) National Centre for Vocational Education Research;

(b) National VET data system;

(c) VET data system.

In this instrument:

***Act*** means the *National Vocational Education and Training Regulator Act 2011*.

***National VET data system contract*** means a VET data system contract relating to a National VET data system.

***VET data system contract*** means a contract under which information technology services relating to a VET data system are to be provided to one or more of the following:

(a) the Department;

(b) VET Regulators;

(c) State or Territory authorities (other than VET Regulators) that deal with, or have responsibility for, matters relating to VET;

(d) the National Centre for Vocational Education Research;

(e) registered training organisations.

***VET data system contractor***, for a VET data system contract, means:

(a) a person who is a party to the VET data system contract and who is responsible for the provision of services under the VET data system contract; or

(b) a VET data system subcontractor for the VET data system contract.

***VET data system subcontractor***, for a VET data system contract, means a person:

(a) who is a party to a contract (the ***subcontract***):

(i) with a VET data system contractor for the VET data system contract (within the meaning of paragraph (a) of the definition of ***VET data system contractor***); or

(ii) with a VET data system subcontractor for the VET data system contract (under a previous application of this definition); and

(b) who is responsible under the subcontract for the provision of services for the purposes (whether direct or indirect) of the VET data system contract.

### Part 2—Circumstances where collection, use or disclosure of information is authorised

###### 5 National VET data systems

(1) For the purposes of subsection 214B(2) of the Act, the circumstances set out in subsections (2) and (3) of this section are specified.

(2) A VET data system contractor for a VET data system contract (that is a National VET data system contract) collecting, using or disclosing information:

(a) for the purpose of designing, building, operating, maintaining or testing the National VET data system to which the contract relates; and

(b) in accordance with the contract.

(3) A person disclosing information to, or collecting information from, a VET data system contractor for a VET data system contract (that is a National VET data system contract) in connection with the VET data system contractor carrying out a purpose mentioned in paragraph (2)(a) in accordance with the contract.

###### 6 Other VET data systems

(1) For the purposes of subsection 214B(2) of the Act, the circumstances set out in subsections (2) and (3) of this section are specified.

(2) A VET data system contractor for a VET data system contract (that is not a National VET data system contract) collecting, using or disclosing information to the extent that subsection (4) applies.

(3) A person disclosing information to, or collecting information from, a VET data system contractor for a VET data system contract (that is not a National VET data system contract) to the extent that subsection (4) applies.

(4) For the purposes of subsections (2) and (3), this subsection applies to the collection, use or disclosure of information if all of the following apply:

(a) the information has been collected in accordance with the Data Provision Requirements, or any equivalent requirements in a non‑referring State;

(b) the collection, use or disclosure is:

(i) for the purpose of facilitating the provision of data in accordance with the Data Provision Requirements, or any equivalent requirements in a non‑referring State;

(ii) if subsection (2) applies—for the purpose of designing, building, operating, maintaining or testing the VET data system to which the contract relates in accordance with the contract;

(iii) if subsection (3) applies—in connection with the VET data system contractor carrying out a purpose mentioned in subparagraph (ii) of this paragraph in accordance with the contract;

(c) if the contract was entered into after the commencement of this section—the VET data system contractor for the contract is obliged under a contract, in relation to information that is:

(i) collected in accordance with the Data Provision Requirements, or any equivalent requirements in a non‑referring State; and

(ii) handled under the VET data system contract;

to comply with the Australian Privacy Principles as if the VET data system contractor were an APP entity (within the meaning of the *Privacy Act 1988*).
