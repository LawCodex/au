# AD/CL-600/74 - Horizontal Stabiliser Trim Actuator Secondary Load Path Indicator

**AIRWORTHINESS DIRECTIVE**

For the reasons set out in the background section, the CASA delegate whose signature appears below issues the following Airworthiness Directive (AD) under subregulation 39.001(1) of CASR 1998. The AD requires that the action set out in the requirement section (being action that the delegate considers necessary to correct the unsafe condition) be taken in relation to the aircraft or aeronautical product mentioned in the applicability section: (a) in the circumstances mentioned in the requirement section; and (b) in accordance with the instructions set out in the requirement section; and (c) at the time mentioned in the compliance section.

#### Bombardier (Canadair) CL-600 (Challenger) Series Aeroplanes

| AD/CL-600/74 | Horizontal Stabiliser Trim Actuator<br>Secondary Load Path Indicator | 8/2007 |
|---|---|---|

| Applicability: | Model CL-600-2B19 aircraft, serial number 7003 and subsequent. |
|---|---|
| Requirement: | Action in accordance with requirements of Transport Canada AD CF-2005-04. |
| Compliance: | As specified in the Requirement document, with a revised effective date of<br>2 August 2007. |
|  | This Airworthiness Directive becomes effective on 2 August 2007. |
| Background: | This Directive mandates the introduction of a Certification Maintenance Requirement (CMR) task into the maintenance schedule; to inspect the Horizontal Stabiliser Trim Actuator (HSTA) secondary load path indicator to ensure that HSTA primary load path failure is detected and corrected. |
